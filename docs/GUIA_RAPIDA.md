# Guía rápida: pokemon-infinito

## ¿Qué es?

Juego de aventuras para móvil. Se conserva independiente y público; sigue siendo un prototipo.

## ¿Cómo lo encuentro?

Puedes abrir el juego desde su despliegue cuando esté disponible. La carpeta `app/` es lo que se publica; GitHub guarda también ideas, pruebas y respaldos.

## ¿Dónde está cada cosa?

| Lugar | Qué encontrarás |
|---|---|
| `app/` | El juego que se abre en el navegador |
| `propuestas/` | Ideas e imágenes todavía por revisar |
| `herramientas/` | Pruebas y tareas de mantenimiento |
| `docs/` | Notas y decisiones |
| `secreto/` | Historia y sorpresas: evita abrirla si no quieres spoilers |

## Qué no debo perder

Antes de cambiar de teléfono, guarda tu partida desde el juego. Los ZIP dentro de este repositorio público pueden verse públicamente.

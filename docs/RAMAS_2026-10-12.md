# Ramas de pokemon-infinito · guía de organización

En palabras sencillas: **`main` es el proyecto actual**. Las otras ramas son mesas de trabajo para probar algo sin alterar esa versión. No es necesario mantener una rama después de integrar su PR; el historial no desaparece de Git.

| Rama | ¿Se integró? | Decisión |
|---|---|---|
| `audit/cleanup-2026-10-12` | Sí, PR #1 | Cerrar al validar su SHA |
| `chatgpt/misiones-2026-10-11` | Sin PR fusionado | Conservar y revisar antes de tocar |
| `chatgpt/recomendaciones` | Sin PR fusionado | Conservar y revisar antes de tocar |

## Cómo recuperar una rama antigua

Si alguna vez hace falta consultar exactamente esa versión, los identificadores (SHA) son:

- `audit/cleanup-2026-10-12` → `8d284feda1a348da52579100a2c7f1863229d4e4`
- `chatgpt/misiones-2026-10-11` → `a0657f2eef1f4f34c89a2a8e6a33db2698738e7f`
- `chatgpt/recomendaciones` → `648316b301981152b0d6245d1b19645f9919fef7`

Las ramas sin un PR aprobado pueden contener trabajo valioso, aunque no sean la versión vigente: **no se borran automáticamente**. Las que ya se fusionaron solo se retiran si GitHub confirma que siguen intactas, sin trabajos abiertos y no están protegidas.
